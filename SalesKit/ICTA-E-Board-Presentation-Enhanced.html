Key Capability

Board Paper Management

No more emailing attachments. Every paper is submitted, reviewed, and approved through a controlled workflow.

📝

Structured Submission

Officers prepare papers with supporting annexures. Multiple file formats up to 20MB per document.

🔍

Three-Stage Review

Director, then CEO. Each can approve, reject with comments, or add sticky-note annotations.

📈

Version History

Every version retained. Rejected papers revised and resubmitted with complete audit trail.

🔔

Automated Notifications

Email notifications at every status change. 33+ templates covering the complete workflow.

🔒

Controlled Access

Three visibility levels ensure confidential papers reach only authorized committee members.

Key Capability

Meeting Lifecycle Management

  • Almanac Planning — Annual meeting schedule tied to financial year with CEO approval workflow
  • Meeting Initiation — Create meetings from approved almanac with auto-populated details
  • 10-Day Board Notice — Automated notice generation with Kenyan governance compliance
  • Agenda Building — Drag-and-drop agenda items, assign papers to each point
  • Attendance Tracking — Digital register with PDF and CSV export
  • Minutes Capture — Per-agenda-item minutes with Word document export
  • Board Resolutions — Record, assign to officers, set due dates, track through completion

Conflict of Interest Register

Board members declare conflicts with OTP email verification and digital signature capture. Exportable as PDF or CSV for compliance records.

Resolution Tracking

Every resolution assigned to a responsible officer with a due date. Status tracked: Pending → In Progress → Completed or Overdue. Nothing falls through the cracks.

Security & Compliance

Enterprise-Grade Security for Sensitive Board Information

🔒

Two-Factor Authentication

OTP-based 2FA via email on every login. 6-digit codes with 5-minute expiry, throttled against brute force.

👤

Role-Based Access Control

10 system roles with granular permissions. Each user sees only what their role allows.

🔐

Account Protection

Auto-lockout after failed attempts. Forced password change on first login. User status enforcement at middleware level.

📑

Comprehensive Audit Trail

Every action logged — who, what, when, from where. Before-and-after values captured. IP address recorded. Exportable as PDF.

📝

Document Access Control

Three visibility levels: all board members, committee-only, or specific named individuals. Download tracking.

✅

CSRF & Encryption

CSRF protection, encrypted cookies, secure sessions, API token auth via Laravel Sanctum.

Implementation

Implementation Timeline

A structured 4-phase engagement with two ICTA Principal ICT Officers on-site throughout.

Phase 1: Platform Setup, Customization & Configuration WEEK 1–2 (14 DAYS)

Server provisioning, E-Board installation, full institutional branding, role configuration, workflow customization, SMTP setup, organizational structure, committee setup, and end-to-end system testing.

Phase 2: Data Migration 3–5 DAYS

Board member onboarding with profiles, photos, and documents. Financial year creation, almanac population with meeting schedule, institutional document upload.

Phase 3: Training 1 WEEK (5 DAYS)

Hands-on role-specific training for Corporation Secretary, CEO, Directors, Division Heads, Officers, and Board Members on their specific workflows.

Phase 4: Go-Live & Handover POST-TRAINING

First board meeting managed end-to-end through E-Board with on-site ICTA support. System handover and documentation.

ICTA Support Team

Two (2) Principal ICT Officers from ICT Authority deployed on-site for the entire implementation period:

  • Platform installation and configuration
  • Institutional customization and branding
  • Data migration and system setup
  • Hands-on training for all user roles
  • Go-live support during first board meeting
  • Knowledge transfer and documentation

Hosting

If your institution has available server space, E-Board can be hosted on your own infrastructure using recommended minimum specifications:

  • PHP 8.0+ with required extensions
  • MySQL 5.7+ or MariaDB 10.3+
  • Apache 2.4+ or Nginx, SSL required
  • Minimum 2GB RAM, 20GB storage
