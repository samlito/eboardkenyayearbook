Key Capability

Board Paper Management

A structured workflow replaces email attachments with controlled, versioned, reviewable board papers.

📝

Structured Submission

Officers prepare papers with supporting annexures. Multiple file formats supported up to 20MB per document.

🔍

Three-Stage Review

Papers reviewed by Director, then CEO. Each reviewer can approve, reject with comments, or add sticky-note annotations.

📈

Version History

Every version of a paper is retained. Rejected papers are revised and resubmitted with a complete audit trail.

🔔

Automated Notifications

Email notifications at every status change — submission, review, approval, rejection. 33+ email templates for the complete workflow.

🔒

Controlled Access

Board members see only papers for their committees. Three visibility levels ensure confidential papers reach only authorized recipients.

Security & Compliance

Enterprise-Grade Security for Sensitive Board Information

🔒

Two-Factor Authentication

OTP-based 2FA via email on every login. 6-digit codes with 5-minute expiry, throttled to prevent brute force.

👤

Role-Based Access Control

10 system roles with granular permissions. Each user sees only what their role allows — from Superadmin to Board Member.

🔐

Account Protection

Automatic lockout after failed login attempts. Forced password change on first login. User status enforcement at middleware level.

📑

Comprehensive Audit Trail

Every action logged automatically — who did what, when, from where. Before-and-after values captured. IP address and browser recorded. Filterable and exportable as PDF.

📝

Document Access Control

Three visibility levels: all board members, committee-only, or specific named individuals. Download tracking on every document.

✅

CSRF & Encryption

Cross-site request forgery protection, encrypted cookies, secure session management, and API token authentication via Laravel Sanctum.

Phase 2: Data Migration Day 3–5

Role-specific training for Corporation Secretary, CEO, Directors, and Board Members. Hands-on sessions with the actual platform.

Phase 4: Go-Live Day 9–10

First meeting managed through E-Board. On-site support during initial board meeting. Handover to ongoing support.
